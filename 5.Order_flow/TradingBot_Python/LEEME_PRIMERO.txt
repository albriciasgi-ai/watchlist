===============================================
   INICIO RÁPIDO (3 PASOS)
===============================================

PASO 1: Iniciar la Aplicación
------------------------------
Haz DOBLE CLICK en:

    START_HERE.bat

Se abrirán 2 ventanas:
  - Backend (Python)
  - Frontend (React)

¡Déjalas abiertas!


PASO 2: Abrir el Navegador
---------------------------
Abre tu navegador en:

    http://localhost:3000

Verás la interfaz del Trading Bot.


PASO 3: Configurar Credenciales
--------------------------------
En el Dashboard:
  1. Panel "Credentials"
  2. Pega tu API Key de Bybit
  3. Pega tu API Secret
  4. Marca "Testnet" ✓
  5. Click "Save Credentials"

¡Listo! Ya puedes operar.


===============================================
   PRUEBA RÁPIDA
===============================================

1. Dashboard → Trading Directions
2. Habilita "BTCUSDT" → Click "BOTH"
3. Ve a pestaña "Alerts"
4. Pega esta alerta de prueba:

   [2025-01-20] [BTCUSDT] ABRIR LONG 50000

5. Click "Process Alert"
6. ¡Observa los logs en tiempo real!
