  📈 STRESS POINTS IDENTIFICADOS

  1. Carga de Datos Masivos (11MB)

  El endpoint /api/double-topbottom/detect recibe hasta 11MB de velas. Sin límites de payload:
  - Timeout en conexiones lentas
  - Memory spike en servidor
  - Potencial DoS con payloads gigantes

  2. Renderizado de 150+ Patrones

  Con 3 años de datos, se detectan ~150 patrones. El canvas itera TODOS en cada frame, incluso si solo 10 son
  visibles.

  3. Múltiples Timeframes Simultáneos

  El backtester maneja 3 timeframes (15m, 1h, 4h) con estado independiente. Cambios rápidos pueden dejar estado
  "fantasma".

  4. WebSocket + HTTP Simultáneos

  El sistema usa WebSocket para tiempo real y HTTP para histórico. Sin coordinación explícita, pueden generar
  estados inconsistentes.

  2. LRU Cache con Límite

  from functools import lru_cache
  from collections import OrderedDict

  class LimitedCache:
      def __init__(self, max_size_mb=200):
          self.cache = OrderedDict()
          self.max_bytes = max_size_mb * 1024 * 1024
          self.current_bytes = 0

      def set(self, key, value):
          size = len(json.dumps(value).encode('utf-8'))

          # Evictar hasta que haya espacio
          while self.current_bytes + size > self.max_bytes and self.cache:
              old_key, old_val = self.cache.popitem(last=False)
              self.current_bytes -= len(json.dumps(old_val).encode('utf-8'))

          self.cache[key] = value
          self.current_bytes += size

  DTB_CANDLES_CACHE = LimitedCache(max_size_mb=150)
  DTB_PATTERNS_CACHE = LimitedCache(max_size_mb=50)
