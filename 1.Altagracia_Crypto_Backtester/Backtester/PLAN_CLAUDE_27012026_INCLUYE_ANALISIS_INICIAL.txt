  Modo 2: Detección Mejorada

  El Range Detector actual probablemente falla por:

  | Problema                                | Solución Propuesta                   |
  |-----------------------------------------|--------------------------------------|
  | ATR muy sensible a volatilidad reciente | Usar ATR de múltiples períodos       |
  | No considera estructura de mercado      | Detectar swing H/L y buscar clusters |
  | Timeframe único                         | Análisis multi-timeframe             |
  | No valida con volumen                   | Volume Profile para confirmar zonas  |

  Algoritmo Propuesto: Cluster de Pivots

  def detect_zones_improved(candles, params):
      """
      1. Detectar TODOS los swing highs/lows
      2. Agrupar por cercanía de precio (clustering)
      3. Filtrar por número mínimo de toques
      4. Validar con volumen (Volume Profile)
      5. Rankear por score de calidad
      """

      # Paso 1: Detectar pivots
      pivots = detect_swing_points(candles, swing_bars=5)

      # Paso 2: Clustering por precio
      # Si varios pivots están dentro de 0.3% de distancia, son "el mismo nivel"
      clusters = cluster_by_price(pivots, tolerance_pct=0.3)

      # Paso 3: Filtrar
      valid_zones = []
      for cluster in clusters:
          if cluster.touch_count >= min_touches:  # ej: 3
              if cluster.duration >= min_duration:  # ej: 4 horas
                  valid_zones.append(cluster)

      # Paso 4: Validar con Volume Profile
      vp = calculate_volume_profile(candles)
      for zone in valid_zones:
          zone.volume_score = get_volume_at_level(vp, zone.price)

      # Paso 5: Rankear
      for zone in valid_zones:
          zone.score = calculate_zone_score(
              touches=zone.touch_count,
              duration=zone.duration,
              volume=zone.volume_score,
              recency=zone.last_touch_time
          )

      return sorted(valid_zones, key=lambda z: z.score, reverse=True)
