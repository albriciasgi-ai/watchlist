  Para futuras sesiones, este es el orden de inicio:

  cd WatchlistConIndicadores/TradingBot_Python/backend
  python main.py

  2️⃣ Iniciar TradingBot Frontend

  cd WatchlistConIndicadores/TradingBot_Python/frontend
  npm run dev

  3️⃣ Iniciar Watchlist Backend

  cd WatchlistConIndicadores/backend
  python -m uvicorn main:app --reload --port 8000

  4️⃣ Iniciar Watchlist Frontend

  cd WatchlistConIndicadores/frontend
  npm run dev

  1. Configurar credenciales en http://localhost:3000
  2. Habilitar los símbolos que quieres tradear

  4. Las alertas del watchlist llegarán automáticamente al TradingBot
